# NS_minerjob
A high-performance, modern Garbage Collector script for ESX, built from the ground up using ox_lib and ox_target. This script features a flexible notification system and seamless NPC interaction.

Features:
- Target Interaction: Uses ox_target for a clean UI-less experience.

- Modern UI: Built with ox_lib for progress bars and skill checks.

- Flexible Notifications: Easily toggle between default ESX notifications, okokNotify, or ox_lib notifications in the config.

- Ped Integration: Includes static NPC interaction at the depot for a professional roleplay feel.

- Optimization: Clean code structure with proper cleanup on resource stops.

Requirements:
- ESX

- ox_lib

- ox_target

Integration:
_ okokNotify
